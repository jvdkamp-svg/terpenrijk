# Terpenrijk

Realtime strategiespel op het Friese terpenland, als installeerbare web-app.

Spelen: https://jvdkamp-svg.github.io/terpenrijk/

Op de telefoon: open het adres en kies "Zet op beginscherm" (iPhone, Safari) of "App installeren" (Android, Chrome).

De muziek staat als losse bestanden in `music/`; de service worker bewaart alles voor offline gebruik.
